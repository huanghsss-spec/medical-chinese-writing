## 4. 纵向一致性继承契约

### 必须继承

列出上游已经锁定、必须在本节体现的精确锚点和语义锚点，并保留节点编号。

### 允许细化

列出本节可以新增的方法、比较、过程、终点、指标或解释，以及它们归属的上游节点。

### 不得改变

列出研究对象、关系方向、证据身份、数量、任务边界、定稿内容及其他不可静默修改的事项。

### 向后传递

列出本节形成后必须由后续章节、表格、图示或附件继续承接的节点、指标和风险。

## 5. 内容细节配额

### 必须具体呈现

直接支撑本节判断的发现、数据、比较、团队基础和必要边界。

### 可以概括处理

同类方法、重复文献、常识背景和低优先级细节。

### 限制或禁止展开

抢占其他章节职责、未经核实、仅展示技术复杂度或不推进判断的内容。

- [ ] 完成官方要求和本节唯一主要功能
- [ ] 已锁定本节唯一外部任务、不承担的任务和最终落点
- [ ] 防御性解释、结构自述和过程自述已按功能删除、迁移或保留
- [ ] 已读取对应版本的一致性节点切片
- [ ] 必须继承的精确锚点和语义锚点均已体现
- [ ] 新增细节均能归属既有目标或内容节点
- [ ] 未静默增加、删除或改变独立目标、任务、终点和指标
- [ ] 需要向后传递的内容已登记实现位置和传播状态
- [ ] 被上提、下沉、后移或转移承载的信息已记录原位置、目标位置和必须保留的意义单元
- [ ] 必须具体呈现的内容已具体呈现
- [ ] 限制展开的内容未挤占核心论证
- [ ] 每段具有一个清楚的中心任务
- [ ] 抽象判断具有具体对象、动作和条件
- [ ] 对象或层级转换具有真实逻辑桥梁
- [ ] 谨慎措辞准确且未过度分散
- [ ] 引文仍支持重构后的完整主张
- [ ] 字数、格式和前后章节关系符合要求
- [ ] 正式编号分级标题均已加粗，正文编号列举未被误加粗
- [ ] 生物医学符号已按语义设置上标、下标或基线，未把阴性标记与连字符、范围或负号混淆
- [ ] 富文本中的符号边界、后续空格、视觉效果和文本可检索性均正确
- [ ] 模板控件以最终显示和官方要求验收，未把提取伪影误判为正文符号错误
- [ ] 受控同义词按语境使用，未机械并列为斜杠组合
- [ ] 需要回写的决定具有明确来源和确认状态
- [ ] 本节完成后已更新章节实现状态并检查是否需要反向校准总纲
- [ ] Grant研究内容在任务或研究组分解前已交代科学目的和有边界的潜在价值
- [ ] 研究任务按证据形成顺序推进，未把尚待形成的方法、流程或模型预写为既有成果
- [ ] 段末和节末总结具有新的科学信息或转化落点，未评价作者自己的安排
- [ ] 主语在连续语境中自然承接，在主体、对象、模型层级或目的变化时重新锚定，未每句机械补写主语
- [ ] Grant方法或技术路线已建立方法功能映射，无孤立技术和无功能清单
- [ ] 常规、关键、待建立和交付型方法已按论证功能分配篇幅
- [ ] 正式组织任务、科学内容模块、研究阶段和图示节点已分别锁定，未机械一一对应
- [ ] 任务内容与直接关系已一体化呈现，未先孤立分述再用空泛总结补救
- [ ] 多研究组形成的研究对象、模型、观察或判断、后续承接用途、验证和共同主张已建立可核对关系
- [ ] 概念图具有唯一外部任务，每种箭头只表达一种关系，并已核验实际渲染方向和可读性
- [ ] 总领命名、机制层命名和图中标签保持相同证据身份，临床转化落点未越过具体研究阶段
- [ ] 代表性成果已说明实际贡献、对当前任务或指南的支撑及规范来源
- [ ] 扩写优先增加科学关系、判断标准、验证层级和风险备选，未用常规技术填充字数
