# Grant｜医学标书模式

## 目录

- 写作目标
- 整体论证
- 研究意义
- 证据缺口与科学问题
- 假设、目标和研究行为
- 创新性
- 前期基础与可行性
- 预期贡献
- 表达力度
- 局部证据报告

## 写作目标

通过科学问题、证据缺口、研究假设、创新性和可行性形成有说服力的项目论证。允许强化研究意义与预期贡献，但不得强化已经获得的证据，不得把计划、假设或预期写成既有结果。

使用专业、凝练、积极而有边界的语气。说服力主要来自问题的重要性、逻辑链、方法匹配、前期基础和可验证目标，不依赖宏大形容词。

## 整体论证

根据项目特点灵活组织以下逻辑：

> 临床或科学问题 → 已有认识 → 具体证据缺口 → 科学假设 → 研究内容与验证方法 → 创新性 → 前期基础与可行性 → 预期科学贡献 → 潜在临床价值

该结构为非穷举示例，不要求机械采用相同段落顺序。每一步之间建立明确推导关系，避免从局部实验结果直接跳到诊疗格局、指南改变或公共卫生效应。

## 研究意义

说明：

- 疾病或问题造成何种具体负担；
- 哪个临床环节或科学认识受到影响；
- 现有证据为什么不足；
- 解决该问题会推进什么具体认识或后续研究。

可以使用重要、关键、亟待等词，但必须有疾病负担、临床后果或证据缺口支撑。控制频率，不连续堆叠重大、核心、关键、原创和领先。

推荐表达：

- “现有证据尚不足以回答……”
- “阐明上述机制对于理解……具有重要意义。”
- “针对该问题开展研究，有助于……”
- “研究结果可能为……提供理论依据。”

## 证据缺口与科学问题

将“缺口”写具体，避免只说研究不足或尚属空白。说明欠缺的是：

- 特定人群数据；
- 直接比较证据；
- 长期随访；
- 机制验证；
- 外部验证；
- 结局评价；
- 方法学能力。

以上只是示例。根据实际材料说明缺失证据的类型及其医学后果。

把科学问题写成可研究、可验证的问题，不用口号替代。关键科学问题应能够对应研究目标、方法和终点。

## 假设、目标和研究行为

区分不同确定性层级：

- **科学假设**：提出、推测、认为可能；
- **研究目标**：拟评估、拟验证、拟阐明；
- **确定实施的行为**：将纳入、将检测、将比较、将随访；
- **尚未获得的结果**：预期、可能、有望、若假设得到验证。

“将”可用于确定的研究程序，不用于不确定疗效。例如，可写“本研究将比较两组主要终点”，不写“本研究将显著改善患者预后”。

## 创新性

通过比较和具体差异体现创新：

1. 既往研究已经完成什么；
2. 存在哪些明确限制；
3. 本项目新增何种对象、机制、方法、数据或验证；
4. 新增内容为何能推进认识或解决具体局限。

推荐表达：

- “与既往主要关注……的研究不同，本项目将进一步分析……”
- “本研究拟从……层面验证……”
- “该设计有助于弥补现有研究在……方面的不足。”

首次、原创性、国际领先、填补空白、突破性、颠覆性不作绝对禁词，但需要高强度、范围明确且可核实的依据。依据不足时，改为补充相关证据、拓展现有认识、回应尚未充分解决的问题或提供新的验证方法。

## 前期基础与可行性

用已经完成的工作、已有数据、方法条件、样本来源和团队经验支持可行性。前期结果按其真实设计和不确定性报告，不因整体是标书而提高结论强度。

区分：

- 已经完成；
- 正在开展；
- 已建立条件；
- 计划完成；
- 预计达到。

不要把初步趋势写成确定效应，不要用技术成功替代临床可行性，不要用团队经验替代研究设计论证。

## 预期贡献

按证据距离逐层表达：

> 预期直接结果 → 对机制或疾病认识的贡献 → 对后续验证研究的支持 → 潜在临床应用价值

推荐使用：

- “研究结果有望深化对……的认识。”
- “可能为后续干预研究提供候选靶点。”
- “可为进一步优化患者选择提供依据。”
- “有望促进相关结果的临床验证或转化。”

不得从细胞、动物、单中心、小样本或替代终点直接推导改善长期预后、改变指南、重塑诊疗模式或解决重大公共卫生问题。

## 表达力度

可以使用创新、优化、提升、促进、潜在价值等词，但明确对象：提升何种能力或指标，优化何种方法或流程，促进何种验证或转化。

“推动”优先写成“有望促进”并说明作用对象。“突破”仅在存在明确、具体、可验证的知识或技术限制时使用。“升级”通常改为改进、优化、完善或调整。

## 局部证据报告

标书中的前期研究、文献证据和安全性数据仍遵守证据校准规则：

- 实际结果使用与研究设计相符的陈述；
- 假设和解释保留不确定性；
- 计划和预期使用未来指向措辞；
- 不用项目重要性反向证明前期证据可靠；
- 不把可行性数据写成比较疗效证据。
