## 核心原则

把节奏理解为信息释放、证据解释和论证推进的顺序，而不是短句、排比或连接词密度。先确定全文需要使读者接受什么判断，再决定章节、段落、证据和句子的顺序及篇幅。

任何局部修改都应回答：

- 当前内容服务于哪个全文目的；
- 它在本章节承担什么功能；
- 它应具体呈现还是概括收束；
- 它是否抢占其他章节的任务；
- 修改后能否推进读者从已知走向当前结论。

## 科学结构与叙事结构

区分：

- **科学结构**决定研究问题、假设、目标、内容、方法、终点和结论之间是否对应；
- **叙事结构**决定读者以什么顺序理解这些内容、每段承担什么任务、何处需要具体解释和逻辑桥梁。

科学结构正确不表示叙事已经清楚。科学结构锁定后仍可以调整段落顺序、信息配额、团队基础出现位置和抽象—具体关系，只要不静默改变核心主张。

建立读者路径：读者进入章节前知道什么，本节新增什么判断，哪些证据使判断成立，哪些边界仍然存在，以及下一章节将回答什么。

## 全文架构图

在完整写作或重大重构前建立：

1. 一句话中心命题；
2. 目标读者最终需要形成的判断；
3. 章节序列及每章唯一主要功能；
4. 每章的进入点、核心判断和落点；
5. 关键证据和团队基础的首次出现位置；
6. 各章字数和重要性；
7. 跨章节依赖、伏笔和回收关系；
8. 最终结论或项目入口。

若某段不能映射到章节功能，判断其属于遗漏的新功能、错位内容、重复材料还是应删除的细节。不要用过渡词把无归属内容强行接入。

## 证据角色与信息配额

为证据和材料分配角色：

- **核心锚点证据**：直接支撑中心问题或主要结论；
- **现状证据**：界定领域认识；
- **边界证据**：说明研究不能支持什么或适用范围；
- **桥接证据**：连接不同机制、细胞类型、阶段或研究层级；
- **团队基础**：支持假设、模型、方法或可行性；
- **方法可行性**：说明工具、样本和流程能够回答问题；
- **备用背景**：相关但非当前论证必需。

给每项材料一个主要论证任务。避免一条有限证据同时承担现状、机制、临床意义和创新性。

按重要性分配篇幅：核心问题、具体发现、证据缺口和直接相关团队基础优先；模型名称、技术参数、低相关文献和履历信息根据章节任务控制篇幅。

## 三个层级的节奏

### 宏观节奏

控制全文中背景、证据、缺口、团队基础、研究任务、结果解释和结尾的顺序与比例。避免背景过长、团队基础过晚、方法先于问题或结尾重复前文趋势。

### 段落节奏

让每段围绕一个中心任务组织若干信息节拍，例如：

> 定位问题 → 具体证据 → 综合解释或边界 → 未决问题 → 团队基础或下一步

或：

> 主要发现 → 与既往研究比较 → 可能解释 → 限制 → 意义

这些是可变结构，不要求每段具有相同句数和顺序。

### 句子节奏

用句子长度和结构反映信息层级。具体结果可直接呈现，复杂条件和边界可适度展开，段末使用清楚的综合判断。不要为制造节奏把完整医学关系拆成连续短句，也不要在一句中堆积多个独立判断。

## Grant节奏

根据章节功能组织：

> 重要问题 → 具体认识 → 证据边界 → 可验证缺口 → 团队切入点 → 项目行动 → 预期增量

遵循：

- 在开篇、范围转折和结尾适度提高论述力度；
- 在文献证据和前期结果句中保持具体、克制；
- 把团队基础放在其所回应的缺口之后，不统一堆到全文末尾；
- 用具体增量体现创新，不连续堆叠重要、关键、首次和领先；
- 章节末尾优先落到未决问题和项目推进方向，不机械重复领域趋势；
- 允许有依据的宏观综合表达，但不得用宏大语句替代证据。

研究现状可采用：

> 病理或临床过程 → 代表性具体发现 → 现有模型或证据限制 → 团队基础 → 下一科学问题

避免按发表时间逐篇介绍文献。

## Journal节奏

根据体裁和章节组织。原始研究通常遵循：

- 引言：背景快速收束至具体缺口和研究目的；
- 方法：按研究设计和可复现顺序组织，不加入价值判断；
- 结果：按预设问题、分析层级、时间或终点推进；
- 讨论：主要发现、比较、解释、局限和意义形成连续路径；
- 结论：直接回答研究问题，不增加未分析内容。

毕业论文可以更充分解释背景和方法原理，但不得通过重复扩展篇幅。期刊论文提高数据和论证密度，减少摘要、结果和讨论间的无效复述。

综述、病例和指南解读按相应体裁组织，不把 Journal 等同于固定 IMRaD。

## 局部构篇

处理章节或段落前：

1. 读取全文中心命题；
2. 写出当前章节的一个主要任务；
3. 写出当前段落准备形成的一个中心判断；
4. 按证据角色归并材料；
5. 选择能推进中心判断的具体发现；
6. 处理真实分歧、边界和缺失信息；
7. 安排段落进入点和落点；
8. 再处理连接词、句式和措辞。

同时为内容分配“必须具体呈现、可以概括处理、限制或禁止展开”三类配额。生成后检查限制展开的模型、探针、细胞系、算法、参数或低优先级文献是否再次挤占核心证据。

若用户只提供一个段落且没有完整总纲，建立最小层级：

> 全文目的 → 章节功能 → 当前段落任务 → 证据 → 边界 → 落点

## 逻辑桥梁

区分“连接词”和“逻辑桥梁”。

- 连接词只显化已经存在的关系；
- 逻辑桥梁说明为什么研究对象、机制、阶段或证据层级能够合理推进。

从肿瘤细胞死亡转向免疫细胞功能时，需要已有材料支持的中间联系，例如死亡相关产物、胞外代谢物或微环境变化；不能只用“与此同时”换话题。

从外部证据转向团队基础时，先指出外部证据留下的具体限制，再说明团队基础能够支持哪一步验证。

不得通过过渡句引入材料中不存在的新事实或把并列关系改成因果链。

## 专业可读性

让读者不依赖历史对话也能追踪主要论证：

- 复杂机制先说明它与当前问题的直接关系，再给出必要术语；
- 抽象综合句之后说明具体对象、动作、方向和条件；
- 避免连续堆叠“状态、代谢、稳态、死亡、免疫”等概念而缺少中间过程；
- 证据句保持边界，缺口句直接指出缺少何种证据，研究行动句清楚说明将做什么；
- 一个边界句能够约束同组主张时，不在每句重复“可能、提示、尚不明确、仍需验证”；
- 不用口语比喻替代医学机制，也不因正式语域省略必要解释。

若一段术语正确，但主体、对象、模型层级或行动目的已经转换而读者仍需自行还原主语和作用方向，先修复叙事结构，再进行语言精修。同一主体的连续动作可自然承接，不要为了形式完整而反复补写主语。

### 长句与逗号串联的重构

长句的核心问题通常不是字数本身，而是多个功能单元没有层级。先标出：研究对象、操作、比较、结果、解释、限制和下一步。保留推进中心判断的单元，删除低价值技术枚举，再按下列关系组织。若没有项目账本、材料覆盖状态或章节任务书足以判断哪些技术细节可以删除，优先归并同类信息而不是实质删除：

- 方法或设计 → 要解决的问题；
- 机制或过程 → 观察结果或预期后果；
- 主要判断 → 必要条件或证据边界。

拆分后检查主体是否能够由连续语境稳定承接。主体、研究对象、模型层级、时间阶段或行动目的变化时，使用准确对象名称、“上述体系”或“该模型”等重新锚定；连续动作中不机械重复“本研究”。必要时增加一处真实桥梁，随后检查相邻句的长度与节奏。不得把原句机械切为两个仍由多个逗号串联的句子。

## 按论证价值压缩

面对硬性字数限制时依次执行：

1. 锁定写作目的、中心问题和章节任务；
2. 锁定核心锚点证据、直接相关团队基础和必要边界；
3. 分配章节和段落字数；
4. 删除重复背景、同义结论和空泛意义；
5. 合并同类证据，保留最能推进判断的具体发现；
6. 删除不影响判断的模型、参数、履历和低优先级文献细节；
7. 保留跨层级推进所需的逻辑桥梁；
8. 最后压缩句式和修饰语；
9. 重新检查信息覆盖账本和引文对应。

不要把“发生了哪些具体变化”压成“细胞状态发生变化”，同时保留次要方法名称。信息密度指单位篇幅的论证价值，不等于单位篇幅的术语数量。

## 按论证价值扩展

用户要求扩写或当前章节缺少必要说明时，优先依次补充：

1. 尚未说明的科学关系、证据差异和对象转换桥梁；
2. 关键方法的必要性及其拟区分的判断；
3. 观察指标、比较关系、判断标准和验证层级；
4. 质量控制、局限、风险和替代方案；
5. 上位模板、复现需求或章节功能确有需要时，再展开必要的常规方法细节。

不仅为达到字数而增加技术、仪器、软件或分析步骤清单。现有材料不足以支持有信息量的扩写时，标记缺失信息，不生成虚假细节。

## 内部策略与外部正文

区分内部风险控制和正式文本。

“仅进行必要适配”“不将某技术作为主要任务”“为避免评审质疑”等内部策略通常不直接写入立项依据或研究现状。根据章节功能：

- 转换为正向、具体的方法范围；
- 放入风险控制或方法说明；
- 与当前章节无关时删除。

同样区分“用于证明合规的内部推理”和“评审需要阅读的正文”。类别豁免、周期、经费、团队配置或任务数量可以在控制文档中说明；正式正文优先呈现已经形成的研究安排、指南映射和完成标准。只有上位模板要求解释，或不解释会造成实质误读时，才把必要依据压缩后写入正文。

不得为了显得稳妥而在正文中暴露不必要的能力焦虑，也不得为了说服力隐藏真实技术限制。

## 检查清单

检查：

1. 每个章节是否承担清楚且不重复的主要功能；
2. 最强证据是否具体呈现；
3. 次要技术细节是否挤占核心证据和团队基础；
4. 团队基础是否出现在能够降低相应风险的位置；
5. 每次对象或层级转换是否具有真实桥梁；
6. 段落是否在证据后形成解释、边界或推进；
7. 压缩是否保留论证密度而非只保留术语；
8. 结尾是否推进全文目的，而非重复趋势或口号；
9. Grant 修辞强弱是否有意分布；
10. Journal 是否围绕实际研究问题、结果和边界；
11. 删除所有连接词后，结构是否仍然成立；
12. 科学结构已锁定时，叙事调整是否仍保持核心主张不变；
13. 抽象判断是否具有具体对象、动作、方向和条件；
14. 限制展开的技术细节是否仍挤占核心证据。
15. 长句是否经过功能归并和低价值删减，而非仅按标点拆分；
16. 拆分后主体是否可由语境稳定承接，并在对象或层级变化时重新锚定。
17. 扩写是否增加了论证价值，而非仅增加术语和方法数量。
