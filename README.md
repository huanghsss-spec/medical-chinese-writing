# 医学中文写作 Skill

`write-medical-chinese` 是一套面向中文医学写作的 Codex Skill，覆盖项目写作规划、内容型总纲、初稿撰写、局部构篇、语言精修、压缩扩写和提交前审校。

当前版本：`v1.2.0`

## 主要功能

- 支持 `Grant` 与 `Journal` 两种医学写作模式；
- 从申报指南、投稿要求、传统大纲、文献、数据和前期基础开始介入写作；
- 为持续性项目建立 `MEDICAL_WRITING_BRIEF.md` 写作主控文档；
- 把标题目录扩展为包含现有信息、统领性问题和精炼回答的内容型总纲；
- 建立指南要求矩阵、章节任务书、字数预算和跨章节对应表；
- 自动识别或联合调用全文建构、局部构篇和语言精修；
- 分别完成结构审计和语言审计；
- 保持医学事实、数据、引文、证据强度、因果边界和适用范围；
- 识别商业化、互联网化、宣传性和口号式表达；
- 根据全文目的处理过渡、证据顺序、团队基础位置和叙事节奏。

## 两种文体模式

| 模式 | 适用内容 | 表达重点 |
|---|---|---|
| `Grant` | 医学基金标书、项目申请、立项依据、研究目标、技术路线、创新性和可行性论证 | 科学问题、证据缺口、团队基础、创新增量、可行性和预期贡献 |
| `Journal` | 毕业论文、期刊投稿、综述、病例报告、指南解读和研究报告 | 研究问题、方法、结果、证据边界和克制解释 |

模式不明确且不同选择会改变结构或语气时，Skill会提供简短说明、推荐及理由，再由用户确认。

## 三个写作层级

| 层级 | 适用任务 | 默认后续处理 |
|---|---|---|
| 全文建构 `architecture` | 从零撰写、建立内容型总纲、规划或重构完整标书与论文 | 局部构篇 → 语言精修 |
| 局部构篇 `composition` | 撰写或重构章节、段落、证据顺序和逻辑桥梁 | 语言精修 |
| 语言精修 `polish` | 结构确定后的术语、句式、证据措辞和格式 | 语言审计 |

用户只要求语言润色，但正文存在需要重排章节、删除重要证据或重新分配篇幅的结构问题时，Skill会说明原因并提供推荐处理范围。

## 项目写作主控文档

对完整标书、论文和持续性写作项目，Skill会读取或协助建立：

```text
MEDICAL_WRITING_BRIEF.md
```

主控文档记录：

- 写作目的、目标读者和活动交付物；
- Grant或Journal；
- 核心科学问题、假设或中心结论；
- 指南、模板和字数要求；
- 内容型总纲和章节功能；
- 证据、团队基础和材料归属；
- 术语口径、用户决策和待核实事项；
- 版本及实质性变更。

后续进行全文、章节或语言处理时，Skill先读取该文件，使局部修改继续服务于全文目的。

主控文档保存精炼内容和来源指针，不复制全部原始数据、文献和历次正文。跨设备使用时，应将主控文档与项目材料一起同步。

## 内容型总纲

内容型总纲不是标题目录。它需要包括：

- 统领性问题及压缩回答；
- 每个章节的功能、核心判断和精炼内容；
- 外部证据、团队基础和证据边界；
- 指南要求矩阵和章节任务书；
- 科学问题、目标、内容、方法、终点和创新性对应；
- 字数预算、信息来源和处理状态。

没有现成大纲时，Skill会先协助建立。用户要求直接完成全文时，Skill仍会先在内部形成内容型总纲，再进入正文。

## 工作流程

```text
读取或建立写作主控文档
        ↓
获取指南、模板、现有大纲和基础材料
        ↓
建立或更新内容型总纲
        ↓
确定Grant或Journal
        ↓
全文建构 / 局部构篇 / 语言精修
        ↓
结构审计
        ↓
语言审计
        ↓
回写已确认的项目级决策
```

## 用户介入节点

用户主要在以下节点介入：

1. 首次建立项目时确认交付物、模式和关键指南；
2. 完整标书、论文或重大重构时确认内容型总纲；
3. 不同材料在事实、数据、证据或成果归属上冲突；
4. 当前授权不足以完成必要的重大结构调整；
5. 最终提交前确认未发表数据、敏感信息和待核实事项。

术语统一、普通句序、必要过渡、重复压缩、字数统计、来源映射和常规审计默认自动完成。

## 安装

### 从 GitHub Release 下载

1. 下载对应版本的ZIP文件并解压；
2. 将其中的 `write-medical-chinese` 文件夹复制到个人Skills目录：

```text
$HOME/.agents/skills/
```

3. 如果Skill没有立即出现在列表中，重启Codex。

安装后的结构应为：

```text
$HOME/.agents/skills/write-medical-chinese/SKILL.md
```

### 从仓库安装

下载或克隆本仓库后，将仓库中的 `write-medical-chinese` 文件夹完整复制到 `$HOME/.agents/skills/`。不要只复制 `SKILL.md`；参考规范、模板和界面元数据均需保留。

## 调用示例

建立Grant项目：

```text
使用 $write-medical-chinese，采用Grant模式。读取申报指南和现有基础材料，先建立写作主控文档和内容型总纲，确认后撰写标书初稿。
```

撰写局部章节：

```text
使用 $write-medical-chinese，沿用当前项目的Grant模式，撰写“国内外现状及趋势分析”。先读取主控文档和章节任务书，再完成局部构篇和语言精修。
```

期刊论文全文：

```text
使用 $write-medical-chinese，采用Journal模式，根据研究目的、方法、结果和目标期刊要求建立内容型总纲并撰写论文初稿。
```

仅做语言精修：

```text
使用 $write-medical-chinese，保持现有结构、数据和引文范围，只进行语言精修和语言审计。
```

结构审计：

```text
使用 $write-medical-chinese 审计这份标书的内容型总纲、章节职责、字数预算以及科学问题—目标—内容—方法的对应关系。
```

## 设计原则

- 先明确写作目的和内容型总纲，再处理局部语言；
- 所有重要材料都要有来源、归属和处理状态，但不机械堆入正文；
- 过渡来自真实论证关系，不靠连接词掩盖结构断点；
- 限字压缩按论证价值取舍，优先保留核心具体证据；
- 标书可以形成有边界的说服性论证，但不得提高既有证据强度；
- 论文可以说明研究意义，但不得扩大结论适用范围；
- Skill不替代临床判断、统计审查、伦理审查和独立事实核查。

## 更新

下载新版本后，用新版 `write-medical-chinese` 文件夹替换旧版。替换前如有个人修改，请先备份或合并差异。项目自己的 `MEDICAL_WRITING_BRIEF.md` 不在Skill目录中，更新Skill时不会被覆盖。
